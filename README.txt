PIKO & ZELLA — UNDANGAN PERNIKAHAN

Isi folder:
- index.html
- assets/bunga-cincin.jpg

CARA MENGGUNAKAN
1. Ekstrak ZIP.
2. Buka index.html di browser untuk melihat undangan.
3. Edit bagian `const CONFIG = { ... }` di akhir index.html:
   - guestName
   - weddingDate (format ISO, contoh 2027-06-12T08:00:00+07:00)
   - tanggal dan jam akad/resepsi
   - venue, address, mapsUrl
   - whatsappNumber (format 628xxxxxxxxxx, tanpa +)
4. Ganti nama orang tua pada bagian HTML jika diperlukan.

Catatan:
- Foto yang Anda kirim sudah dipasang sebagai background cover.
- Font Google akan dimuat jika perangkat terhubung ke internet; fallback tetap tersedia.
- RSVP akan membuka WhatsApp setelah nomor tujuan diisi.
- Semua file aset harus tetap berada dalam struktur folder seperti semula.
